# Verschlüsseltes Archiv

Die `.zip`-Dateien hier enthalten ein **verschlüsseltes** Archiv. Ohne den
passenden Schlüssel sind sie nicht lesbar — auch nicht für den Betreiber
dieses Repositories.

## Öffnen

1. Die neueste `notfall-backup-*.zip` herunterladen und entpacken.
2. `ENTSCHLUESSELN.html` im Browser öffnen (Doppelklick genügt, kein Internet
   und keine Installation nötig).
3. Die entpackten Dateien in das Feld ziehen — auch die beiden aus dem
   Unterordner `schluessel`.
4. Passphrase eingeben **oder** den Schlüssel von einem der Papierbögen.

Es genügt **ein** Schlüssel. Die `ENTSCHLUESSELN.html` in diesem Verzeichnis
ist byte-identisch mit der im Paket; sie liegt hier nur zur Bequemlichkeit.

## Warum das öffentlich liegt

Damit es auffindbar bleibt, wenn alles andere weg ist: Rechner, Papiere,
Verträge, Domains. Der Schutz liegt allein in der Passphrase, nicht in der
Unauffindbarkeit.

Jeder Lauf ersetzt den Stand vollständig — dieses Repository hat bewusst
keine Versionsgeschichte.
